## 🧾 Descrição Geral

Este aplicativo Android simula uma lista de compras com 5 produtos. O usuário marca os itens desejados usando `CheckBox` e, ao finalizar, visualiza o valor total da compra.

### Produtos:
- Arroz 1Kg – R$2,69
- Leite Longa Vida – R$2,70
- Carne Friboi – R$16,70
- Feijão Carioquinha 1Kg – R$3,38
- Refrigerante Coca-Cola 2L – R$3,00

## 🚀 Funcionalidades

- Marcar e desmarcar produtos com `CheckBox`;
- Cálculo automático do valor total da compra;
- Interface simples e intuitiva.

## 💡 Processo de Desenvolvimento

Nesta aplicação, aprimorei o uso de `CheckBox` e manipulação de eventos de clique para somar valores dinamicamente. O foco foi criar uma interface limpa e direta, que simula a experiência de uma compra real de forma simples.
